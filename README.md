# Manikanta Prasad J — Academic Portfolio

A responsive static portfolio website built with HTML, CSS and vanilla JavaScript. It is suitable for free hosting on GitHub Pages.

## Included
- Responsive home, about, expertise, research, invited talks, education and contact sections
- Dark/light theme toggle and mobile navigation
- Resume download (`assets/Manikanta-Prasad-J-Resume.docx`)
- Uploaded profile and professional photos

## Preview locally
Open `index.html` in a browser. For a local server, run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish on GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload the contents of this folder to the repository root: `index.html`, `styles.css`, `script.js`, `assets/`, and this README.
4. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to complete. Your site should be available at `https://YOUR-USERNAME.github.io/`.

## Before publishing
- Confirm that the phone number and email address may be published publicly.
- Verify current designation, experience duration, Ph.D. status, publication titles/status, and event details.
- The site uses Google Fonts from a CDN; if offline use is needed, remove the Google Fonts import in `index.html`.
- The uploaded resume is a DOCX download. You can also add a PDF version if desired.
- Replace or remove any photos that include other people unless you have permission to publish them.
